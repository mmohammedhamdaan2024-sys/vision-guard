# Vision Guard — Evidence Vault

This directory stores visual evidence snapshots captured during traffic monitoring:

- High-resolution frame crops of vehicles involved in suspected violations.
- Region crops: Motorcycle rider head zones, occupant windshield zones, window tint zones, and license plate crops.
- Naming format: `EVID_<YYYYMMDD>_<TRACK_ID>_<VIOLATION_TYPE>_<TIMESTAMP>.jpg`

## Privacy & Data Retention Notice
Evidence images stored here are for local demonstration and administrative review purposes only. Vision Guard features configurable data retention and secure purges through the Settings interface.
