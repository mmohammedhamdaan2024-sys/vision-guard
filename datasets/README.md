# VisionGuard — Datasets Directory

This directory contains configuration files and documentation for public traffic safety datasets:

## 1. Motorcycle Helmet Detection Datasets
* **Kaggle Helmet Detection Dataset:**
  - URL: https://www.kaggle.com/datasets/andrewmvd/helmet-detection
  - Format: Pascal VOC / YOLO bbox annotations
  - Classes: `helmet`, `no_helmet`, `head`
* **Roboflow Universe Two-Wheeler Safety Benchmark:**
  - URL: https://universe.roboflow.com/search?q=helmet+detection
  - License: CC BY 4.0 (Educational/Research)

## 2. Occupant Seat-Belt Datasets
* **Roboflow Driver Seatbelt Compliance Dataset:**
  - URL: https://universe.roboflow.com/search?q=seatbelt
  - Classes: `seatbelt`, `no_seatbelt`, `windshield`
* **AutoData Traffic Safety Benchmark:**
  - URL: https://opendatalab.com/

## 3. Traffic Signal & Light Benchmark
* **Bosch Small Traffic Lights Dataset:**
  - URL: https://hci.iwr.uni-heidelberg.de/content/bosch-small-traffic-lights-dataset
  - Classes: `Red`, `Yellow`, `Green`, `Off`
